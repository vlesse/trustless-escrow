# 测试网上跑起来的东西

装法：把 `*.service` / `*.timer` 拷到 `/etc/systemd/system/`，
`reveal-try.sh` 拷到 `/srv/escrow/`，然后 `systemctl daemon-reload`。

## escrow-keeper.service

常驻。推进协议里那些「任何人都可以做、但没人会主动做」的步骤：
抽签、开揭示、计票、结案、沉淀信誉记录。

这把钥匙能做的每件事合约上任何人都能做，它碰不到资金也没有管理员权限，
所以可以热放在机器上。但**不要和提案人的钥匙（要质押、会被罚没）或
管理员的钥匙（能停新单）共用** —— 三者的风险等级完全不同。

`POLL_INTERVAL_MS` 和链的出块速度绑死，不是性能参数。`blockhash` 只能
回溯 256 个区块，BSC 上 256 块只有约 115 秒。轮询慢于这个窗口，抽选会
反复过期重排，案件一路耗到超时以拒裁收场，**而两边都不会有任何报错**。
启动时会按链上实际出块速度核一遍，太长直接拒绝启动。

## escrow-reveal.timer

每 30 分钟试一次陪审员揭示。揭示窗口只有 2 天，错过的席位被当作弃权
并罚没质押 —— 人不可能守在那里等，所以这一步必须自动化。
脚本幂等，阶段不对就静默退出。

这只是模拟场景用的。真实陪审员的揭示由他们自己负责。
